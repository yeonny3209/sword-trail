# 검의 궤적 (Sword Trail)

3인칭 근접 검술 액션 + 로그라이트 전투 프로토타입. 그래픽 없이 캡슐·상자만으로 "상자끼리 싸워도 재미있는 전투"를 목표로 한다.

**플레이:** https://yeonny3209.github.io/sword-trail/ (PC 브라우저, 키보드·마우스)

## 조작
| 입력 | 동작 |
| --- | --- |
| WASD / 마우스 | 이동 / 시점 |
| 왼쪽 클릭 | 약공격 3타 콤보 |
| Shift+왼쪽 클릭 | 강공격(0.4초 차지) |
| 오른쪽 유지 | 막기 — 맞기 직전에 누르면 패링 |
| 스페이스 | 구르기(무적) |
| 휠 클릭 / Tab | 적 고정 |
| Q / E / F | 검 기술 / 회복약 / 상호작용 |
| F1 / H | 디버그 화면 / 조작법 |

적 검의 **흰 빛**은 패링 가능, **붉은 빛**은 회피만 가능.

## 개발
```bash
npm install
npm run dev
```
Three.js + TypeScript + Vite + Rapier. 모든 수치는 `data/`의 JSON. 구조와 규칙은 [CLAUDE.md](CLAUDE.md).
