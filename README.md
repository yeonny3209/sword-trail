# 검의 궤적 온라인 (Sword Trail Online)

쿼터뷰 3D 액션 MMORPG. 웹 브라우저(PC)에서 여러 명이 같은 월드에 접속해 사냥하고, 성장하고, 거래하고, 겨룹니다.
전투는 던파식 콤보 액션(띄우기·공중 콤보·대시·백스텝·스킬)입니다.

이전 로그라이트 버전은 git 태그 `roguelite-v1`에 남아 있습니다.

## 할 수 있는 것
- **직업 4종**: 검사(균형), 광검사(대검·슈퍼아머), 쌍검사(속도·연타), 마검사(검기·원거리). 직업마다 스킬 6개(Lv20 궁극기 포함)
- **성장**: 레벨 40, 스탯 분배(힘·민첩·체력·지능), 스킬 레벨, 장비 7부위·등급 5단계·무작위 옵션·강화 +15, 채집·제작(제작법 58개)
- **월드**: 산기슭 마을 + 사냥터 4곳(Lv1~30) + 결투장, 몬스터 14종과 필드 보스 3마리, 퀘스트 20개
- **함께**: 지역·전체 채팅, 귓속말, 파티(최대 4명, 경험치 나눔·드랍은 각자), 길드, 1:1 거래, 경매장, 우편함, PvP 결투장과 순위표
- **레이드**: 마을 남쪽 문으로 들어가는 파티 전용 던전 「무너진 성채」(Lv10+). 보스 가르곤은 인원이 많을수록 체력이 늘고, 체력 단계마다 부하를 부르며, 큰 공격은 바닥에 붉은 범위가 먼저 뜹니다. 처치하면 참여한 모두가 장비 보상

## 조작
| 입력 | 동작 |
| --- | --- |
| WASD | 이동(화면 기준) · 같은 방향 두 번 = 대시 |
| 마우스 | 공격 방향 |
| 오른쪽 버튼 누른 채 드래그 | 카메라 돌리기 (Home = 원래 방향, WASD는 항상 보이는 화면 기준) |
| 왼쪽 클릭 / X | 기본 공격 4타 콤보 |
| 스페이스 | 점프 · NPC 대화 · 채집 |
| Z | 백스텝(무적) |
| Q E T F G R | 스킬 |
| C / V | HP / MP 물약 |
| I U K L | 인벤토리 / 캐릭터 / 스킬 / 퀘스트 |
| P / N | 파티 / 길드 |
| Enter | 채팅 (`/전체` `/파티` `/길드` `/w 이름` `/r` `/초대 이름` `/도움`) |
| 다른 플레이어 오른쪽 클릭(끌지 않고 짧게) | 귓속말 · 파티 초대 · 거래 신청 · 길드 초대 |
| Esc | 창 닫기 |

## 로컬에서 실행
```bash
npm install
npm run dev
```
`http://localhost:5173` 에 접속합니다(로컬 Cloudflare 서버 :8787 + 클라이언트 :5173). 처음 한 번은 자동으로 로컬 DB 테이블을 만듭니다.

- `npm run check` 타입 검사, `npm test` 단위 테스트
- 서버가 켜진 상태에서 `node scripts/smoke-social.mjs` 처럼 연기 테스트(`smoke`, `smoke-social`, `smoke-party`, `smoke-market`, `smoke-pvp`, `smoke-raid`)

## 인터넷에 공개하기 (Cloudflare 무료 플랜)
Cloudflare 계정만 있으면 됩니다(카드 등록 불필요).

1. 로그인: 브라우저가 열리면 허용을 누릅니다.
   ```bash
   npx wrangler login
   ```
2. 첫 배포(데이터베이스 만들기 → 테이블 만들기 → 빌드 → 배포를 한 번에):
   ```bash
   npm run cloud:setup
   ```
   끝나면 `https://sword-trail-online.<내 하위 도메인>.workers.dev` 주소가 나옵니다. 이 주소를 친구에게 보내면 함께 플레이할 수 있습니다.
3. 그다음부터 코드를 고쳤으면 `npm run deploy`, `server/migrations/`에 새 파일이 생겼으면 먼저 `npm run db:migrate:remote`.

무료 플랜 참고: 소수 인원(친구들끼리)이 즐기기에 충분합니다. 존 서버는 사람이 있을 때만 돌고, 이동은 초당 10번만 보냅니다.
많은 사람이 오래 접속하면 하루 무료 한도(Durable Objects 요청·실행 시간)에 걸려 그날은 접속이 거절될 수 있습니다.

Three.js + TypeScript + Vite(클라이언트), Cloudflare Workers + Durable Objects + D1(서버). 모든 수치는 `data/`의 JSON.
